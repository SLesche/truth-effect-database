This Folder contains data from the following publication:

Stump, A., Rummel, J., & Voss, A. (2020). Is it all about the feeling? Affective and (meta-)cognitive mechanisms underlying the truth effect.

TruthData_Experiment1.sav contains the following information:
	- Subject 
	- Session
	- Age
	- Gender (weiblich=female; männlich=male)
	- Language (deutsch=German; andere=other)
	- Major
	- Confidence.RESP
	- Confidence.RT
	- TruthRating (0=false; 1=true)
	- TruthRating.RT
	- Fluency (0=new; 1=repeated)
	- Valence (0=neutral; 1=positive, 2=negative)
	- ItemID
	- StatementType (0=false; 1=true)
	- statement
	- NCC
	- PI
	- PD
	- Set (0=first photo set which included KDEF images; 1=second photo set which included RaFD and WSEFEP images)
	- Emotion (0=persons who did not notice the affective priming; 1=persons who noticed the affective priming)
	- Hypothese (0=persons who did not describe any appropriate hypothesis; 1=persons who stated at least one appropriate hypothesis regarding the aim of this study)

As stated in the manuscript, we have excluded the data of the following participants (Subject) before the analyses:

13, 70, 101, 118, 119, 36, 51, 57, 59, 6, 85, 89

	

TruthData_Experiment2.csv contains the following information:
	- id
	- session
	- condition (0=control group; 1=affect attribution group)
	- order 
	- age 
	- gender (0=male; 1=female)
	- language (0=other; 1=German)
	- fluency (0=new; 1=repeated)
	- factual_truth (0=false; 1=true)
	- responses (0=false; 1=true)
	- rts
	- confidence 
	- NCC
	- PI
	- PD
	- ItemID
	- NCC_M (0=low NCC; 1=high NCC)
	- PI_M (0=low PI; 1=high PI)
	- PD_M (0=low PD; 1=high PD)


As stated in the manuscript, we have excluded the data of the following participants (id) before the analyses:
63, 22, 38, 7, 29, 45, 46, 48, 65, 77, 35

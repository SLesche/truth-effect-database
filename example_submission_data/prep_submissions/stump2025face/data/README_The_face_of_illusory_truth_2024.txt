This Folder contains data from the following publication:

Stump, A., Wüstenberg, T., Rouder, J. N., & Voss, A. (2024). The face of illusory truth: Repetition of information elicits affective facial reactions predicting judgments of truth. 
Manuscript submitted for publication.


data_femg_truth_effect_2024.csv contains the following information:

	- id
	- session
	- gender
	- age
	- statements
	- statement_type (0=new; 1=repeated)
	- responses (0=false; 1=true)
	- auc_Corrugator
	- auc_Frontalis
	- auc_Zygomaticus

This Folder contains data from the following publication:

Stump, A., Voss, A., & Rummel, J. (2023). The illusory certainty: Information
repetition and impressions of truth enhance subjective confidence in validity judgments
independently of the factual truth. Manuscript submitted for publication.



data_confidence_2023.csv contains the following information:
	- id
	- session
	- age 
	- gender 
	- statements
	- statement_type (0=new; 1=repeated)
	- responses (0=false; 1=true)
	- confidence
